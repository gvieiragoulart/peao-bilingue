Peao Bilingue for Linux (x86_64)

Extract the archive and run ./PeaoBilingue/PeaoBilingue to open the app.
Run ./PeaoBilingue/PeaoBilingue adapters to list its command-line adapters.

This bundle is built on Ubuntu 24.04 and requires a compatible glibc-based Linux
desktop. GNOME Keyring/Secret Service stores API keys, notify-send provides desktop
notifications, and a user systemd session is needed for daily scheduling. Install
Google Chrome to use the VanHack source; the other public sources do not require it.

LICENSE.md and THIRD_PARTY_NOTICES.txt are included in this directory.
